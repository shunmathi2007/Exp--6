# Exp - 6 STUDENT ONLINE EXAM REGISTRATION SYSTEM

# AIM:
To design and develop a Student Online Exam Registration System that allows students to register for examinations online, select the required subjects, and manage their examination registration efficiently.
# SRS (Procedure):
Identify the requirements of the Student Online Exam Registration System.

Identify the users involved, such as Student and Administrator.

Design the system using appropriate UML diagrams.

Create the Use Case Diagram to represent the interaction between users and the system.

Create the Activity Diagram to represent the workflow of exam registration.

Create the Sequence Diagram to represent the interaction between the student and the system.

Create the Communication Diagram to show communication between system objects.

Create the Class Diagram to represent the classes and their relationships.

Create the Package Diagram to organize the system components.

Verify the complete registration process and ensure that the system meets the specified requirements.
